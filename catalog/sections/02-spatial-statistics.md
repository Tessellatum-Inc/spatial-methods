## Principal component analysis

The [PCA record](../../algorithms/statistics/pca.md) documents the tested NumPy implementation in [pca-transform](../../implementations/python/pca-transform/README.md). It fits covariance or correlation PCA, supports a valid-row mask and projects observations into descending-variance component space. A separate [principal-axis factor-analysis baseline](../../algorithms/statistics/factor-analysis.md) models common variance and optional varimax rotation; it is not maximum-likelihood or confirmatory factor analysis. OAC-style geodemographic classification remains a distinct open workflow.

## First audited clustering lesson

The [DBSCAN lesson](../../algorithms/statistics/dbscan.md) introduces core, border and noise points, the eps/min_samples parameters and the input-order policy for ambiguous border points. A tested O(n²) planar implementation and interactive notebook provide a small-data baseline; HDBSCAN, OPTICS and indexed large-data search remain open. The separate [ST-DBSCAN lesson](../../algorithms/statistics/st-dbscan.md) adds a tested joint spatial-and-temporal neighbourhood baseline with deterministic border assignment; T-DBSCAN and indexed spatiotemporal search remain open.

## First audited point-pattern lessons

The [planar Gaussian KDE lesson](../../algorithms/statistics/point-pattern-kde.md) explains the fixed-bandwidth Gaussian kernel, intensity units, projected-coordinate requirement and uncorrected study-window edge effect. A tested NumPy implementation and interactive notebook compare bandwidths and weighted events. The [Clark–Evans lesson](../../algorithms/statistics/clark-evans.md) compares observed nearest-neighbour spacing with a homogeneous Poisson reference, while explicitly withholding a significance claim because this baseline does not apply edge correction or calculate a test statistic. The [Ripley's K/L lesson](../../algorithms/statistics/ripley-k.md) compares pair counts across distance scales with both uncorrected and rectangular-window translation-corrected estimators. The planar Gaussian KDE, Clark–Evans, Ripley's K/L and DBSCAN lessons have tested implementations and notebooks; a conditional Monte Carlo quadrat-count test is now included in the point-pattern lab. Isotropic/border corrections, formal nearest-neighbour inference, fitted intensity models and general inhomogeneous point-process models, adaptive bandwidths and network KDE remain open. The supplied-intensity inhomogeneous K estimator is a bounded summary-statistic implementation, not a fitted point-process model. The [log-Gaussian Cox lesson](../../algorithms/statistics/log-gaussian-cox-process.md) and package add a small-grid exponential-covariance latent Gaussian intensity simulator, with conditional Poisson cell counts; the piecewise-constant field and 225-cell dense-Cholesky limit are explicit. The [Matérn cluster-process lesson](../../algorithms/statistics/matern-cluster-process.md) and point-process package now include a stationary Poisson-parent/Poisson-offspring simulator with uniform disc displacement; its compact-support kernel permits an exact radius-sized parent-window buffer. The supplementary point-process package adds the empirical G function, a Monte Carlo empty-space F function and J=(1-G)/(1-F), plus inhomogeneous K for externally supplied pointwise intensities, finite-difference pair correlation and a conditional multinomial quadrat test. F/J use uniform samples in a rectangular window and are uncorrected teaching estimators; advanced edge correction and F/G simulation envelopes remain open. The package does not fit an intensity surface.

## Network-constrained point-pattern analysis

The [network KDE record](../../algorithms/networks/network-kde.md) and [Python package](../../implementations/python/network-kde/README.md) implement a vertex-sampled Gaussian estimator using shortest-path distance on an undirected weighted graph. Continuous edge integration, within-edge event positions, edge correction, network K and SANET-specific methods remain unimplemented.

### Implemented spatial regression estimators

The [spatial econometrics package](../../implementations/python/spatial-econometrics/README.md) now includes classic and Bera-Yoon robust LM diagnostics, spatial lag 2SLS, spatial Durbin 2SLS, SAR/SDM impact decomposition with parametric Monte Carlo uncertainty intervals, and concentrated Gaussian maximum likelihood for SAR, SEM and SDM, plus joint SARAR/SAC maximum likelihood, Gaussian proper-CAR regression ML and a constrained ICAR field simulator. The ML implementation uses a conservative norm-bounded spatial-parameter interval and dense log-determinants, including a two-parameter SARAR/SAC profile. Parametric Monte Carlo uncertainty intervals for SAR/SDM impacts now propagate a supplied joint coefficient covariance; covariance estimation for the spatial ML estimators, weak-instrument diagnostics, scalable sparse likelihoods, and other model families remain open. A separate [spatial HAC OLS covariance estimator](../../algorithms/statistics/spatial-hac-covariance.md) is implemented with a compact-support Wendland kernel; it does not correct spatial endogeneity.

## Decisions for the next pass

1. Separate global and local spatial autocorrelation from the models used to explain it.
2. Verify each named statistic, test and model against primary or authoritative sources.
3. State the spatial weights, null hypothesis, sampling assumptions and inferential procedure for statistical examples.
4. Distinguish clustering algorithms from regionalisation objectives and constraints.
5. Do not treat a model acronym as a complete specification; document its likelihood, spatial structure, estimation and assumptions.
6. Use synthetic data only when it makes the statistical property easier to see, and state how the data were generated.

# What the collection covers

This matrix connects the original compendium to the work published in this repository. Raster resampling now includes nearest-neighbour, bilinear, Keys cubic and Lanczos-3 interpolation, plus a separate exact-overlap area-weighted aggregation reference for aligned grids. Local raster map algebra now includes tested cellwise reducers/arithmetic and categorical lookup with explicit NoData and unknown-category policies; these additions do not close the broader raster map-algebra or CRS-aware-warp source entries. Terrain coverage now includes hypsometric distribution summaries, aligned-surface cut-and-fill volumes, and a multi-azimuth hillshade composite, alongside TPI and Riley TRI. Terrain morphometry now includes a tested empirical hypsometric curve and integral, in addition to TPI and Riley TRI; its equal-area grid assumption and zero-relief limitation are explicit. Raster hydrology coverage now includes D8 stream-network ordering (Strahler order and Shreve magnitude) on an explicit channel mask, with directed-graph validation and cycle detection. The terrain raster package now includes a tested integral-image topographic position index (focal elevation minus neighbourhood mean), with explicit window-scale and NoData-fraction controls, plus Riley's eight-neighbour square-root-of-sum-of-squares terrain ruggedness index; neither metric is a complete landform classifier. The repository also includes tested aligned-surface cut-and-fill volumes, empirical hypsometric curves/integrals and 3D connected-component labeling with 6/18/26-neighbour connectivity. Section 1 approximate search now includes a bounded random-hyperplane LSH reference for cosine similarity, with tests and a dedicated lesson; HNSW, IVF-PQ and ScaNN remain open. Section 6 now also includes a deterministic greedy VRPTW construction with service schedules, waiting, capacity and depot-return checks; exact and advanced VRPTW methods remain open. It is deliberately conservative: a topic is not marked researched or implemented just because its name appears in the source transcription.

**Status key**

- **Captured** — the source text is preserved in the page transcription.
- **Mapped** — the original section is indexed and its scope is visible.
- **In progress** — at least one canonical record or implementation exists, but the section is not comprehensively covered.
- **Not started** — no reviewed canonical coverage has been published yet.

## What this tells us

The repository now has a connected geometry foundation, a spatial-index foundation and a filter-and-refine spatial-join lesson, alongside a researched spatial-autocorrelation sequence. It still does not cover the breadth of the 47-page source. The next stage is not to create hundreds of shallow pages. ## Section 7 implementation note

The ELECTRE I-style package now contains two deliberately separate stages: pairwise relation construction and exact small-instance kernel enumeration. The kernel enumerator checks internal and external stability, reports every kernel, and explicitly reports when no kernel exists. It is exhaustive and capped at 20 alternatives by default; it does not perform cycle reduction or produce a total ranking. See the [method record](../methods/electre-outranking.md), [implementation contract](../implementations/python/electre-i/README.md), [kernel exercise](../exercises/electre-i-kernel.md) and [kernel lab](../notebooks/electre-i-kernel-lab.ipynb).

## Section 2 implementation note

G/F/J nearest-neighbour functions now have a tested empirical implementation: G uses event-to-nearest-other-event distances, F uses supplied independent empty-space test locations, and J is their survival-function ratio with explicit zero-denominator handling. The latter returns pointwise quantile bands and a separate global studentised maximum-deviation Monte Carlo p-value across a preselected radius interval. ## Section 6 implementation note

## Section 3 implementation note

The standalone IDW package supplements the combined interpolation lesson with a dependency-free implementation, coincident-observation policy, optional neighbourhood restrictions, tests, intern walkthrough and an interactive notebook. The location set-covering package adds an exact small-instance solver that minimizes the number of sites needed to cover every demand row within a supplied threshold. See the [lesson](../algorithms/optimization/set-covering.md) and [package](../implementations/python/set-covering/README.md).

The Section 6 equity-constrained maximal-covering addition provides an exact tiny-instance model that maximises covered objective weight subject to population-weighted minimum coverage floors for each caller-defined group. It includes separate demand and objective weights, infeasibility handling, tests, an intern walkthrough, exercise and executable lab. The Section 6 backup-coverage extension adds an exact small-instance r-covering solver, tests, intern walkthrough, exercise and executable notebook. It does not estimate failure probabilities or operational reliability, and shared dependencies must be examined separately.


The Section 6 queueing extension adds a dependency-free M/M/c implementation using Erlang-C, tests for the M/M/1 closed form, server sensitivity, Little's law and stability, plus an intern walkthrough, exercise and notebook. It is a stationary FCFS model with Poisson arrivals, exponential service and identical servers; it does not replace travel-time accessibility or model time-varying arrivals.

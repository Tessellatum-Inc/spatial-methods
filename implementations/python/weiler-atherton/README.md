# Weiler–Atherton polygon intersection\n\nA linked-boundary implementation for intersection of two simple polygon rings. Supports concave inputs, disconnected area outputs, containment and disjointness. It explicitly rejects point-touch and collinear-overlap events and does not model holes.\n\nThe implementation inserts paired intersection nodes in edge order, classifies entry arcs, and traverses interior boundary arcs by transferring between subject and clip rings.\n\nRun `python -m pytest -q` in this directory. Tests are authored but require execution in an environment with pytest.

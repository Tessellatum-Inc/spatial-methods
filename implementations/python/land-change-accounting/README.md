# Land-change accounting

Implements categorical transition matrices, per-class persistence/gains/losses/net change/swap, quantity and allocation disagreement, and annualized interval/category gain/loss intensity summaries. Classes and masks are explicit; unknown categories are rejected when a class order is supplied. Intensity measures are descriptive accounting rates, not causal explanations. This is a two-date accounting baseline and does not implement legend harmonization, uncertainty propagation or the complete multi-interval Pontius intensity-analysis significance framework.

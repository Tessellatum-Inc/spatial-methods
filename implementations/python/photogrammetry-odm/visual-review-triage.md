## Interpretation

These examples show why the visual review cannot be reduced to checking whether a yellow overlay lands near a visible object. Some picks appear associated with large built features or linear edges; the relevant question is whether the *same well-defined physical point* is identifiable across views and whether the source pixel coordinate is centred on it.

The review should distinguish:

- target visibility from target identity;
- feature recognition from precise centre definition;
- cross-image consistency from independent measurement;
- visual plausibility from surveyed-coordinate correctness.

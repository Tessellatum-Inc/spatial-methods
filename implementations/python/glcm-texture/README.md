# GLCM texture features

Builds gray-level co-occurrence matrices (GLCMs) for explicit pixel offsets and derives contrast, dissimilarity, homogeneity, angular second moment (ASM), energy and correlation.

```python
from glcm_texture import glcm, glcm_features
matrices = glcm(image, levels=32, offsets=((0,1),(1,0),(1,1),(-1,1)))
features = [glcm_features(m) for m in matrices]
```

Quantization uses a fixed or image-derived value range. Set a fixed range when comparing scenes or dates; otherwise each image is independently stretched and feature values may not be comparable. Invalid pixels and the optional boolean mask remove pairs if either endpoint is invalid. Symmetric matrices are the default. A zero-variance marginal receives correlation 1 by convention. These are common Haralick-style features, not the complete 14-feature Haralick set; windowed texture rasters should be generated by a separate moving-window driver.

Run tests with `pytest -q` from this directory.

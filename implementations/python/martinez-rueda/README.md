# Martinez–Rueda polygon overlay — staged implementation

The implementation now provides endpoint event ordering, active x-overlap candidate testing, cross-source segment intersections, segment splitting, midpoint inside/outside classification for intersection/union/difference/XOR, and directed-fragment stitching into closed output rings. It returns oriented rings; clockwise rings represent holes. Disconnected outputs are returned as multiple rings. Difference and symmetric difference reverse the relevant interior fragments to preserve ring orientation.

**Still incomplete:** the active set checks all x-overlapping pairs and is quadratic in the worst case; it is not the full Martinez–Rueda neighbour-ordered sweep-status algorithm. Input is restricted to exactly one valid simple shell ring per source (no input holes or MultiPolygon input). Positive-length collinear overlaps and touching/near-coincident boundary configurations are not fully supported. The result is a flat oriented-ring collection rather than explicit Polygon/MultiPolygon grouping with shell-to-hole ownership. Numerical predicates use a simple absolute epsilon, not adaptive exact arithmetic.

Run `python -m pytest -q` in this directory.

## Result

The full-pilot public Earth Search retrieval artifact was downloaded and its provenance CSV inspected.

| Measure | Observed |
|---|---:|
| Blind-review points in input | 25 |

Every one of the 25 blind-review points therefore has at least one successfully retrieved RGB chip from a 2021 public Earth Search candidate. This is a retrieval-coverage result, not a statement that the imagery is suitable for adjudication or that any point has been correctly classified.

## Failure diagnosis

All 14 failed attempts report the same access issue: candidate assets were exposed through the `sentinel-s2-l2a` S3 bucket, for which the current runtime has no credentials. These failures are not evidence of absent imagery or invalid coordinates. The same point often has other candidate scenes that were successfully read from public assets.

The immediate engineering improvement is to make asset selection more explicit about access class:
- retain public HTTPS and the known anonymous `sentinel-cogs` path;
- identify credential-gated S3 assets before attempting raster reads;
- record them as `inaccessible_requires_credentials` (or an equivalent distinct status), rather than grouping them with generic raster/chip failures;
- continue to later public candidates when an earlier candidate is inaccessible.

No credentials should be requested in chat, committed to the repository, or introduced as a prerequisite for this pilot.

## Important limitations

1. The 61 successful outputs are RGB chips, not multispectral band stacks.
2. Three candidates per point were attempted; this is not an exhaustive search of all 2021 acquisitions.
3. Candidate rows can represent overlapping or near-duplicate acquisitions/assets. Candidate count is not the count of independent dates.
4. Scene-level cloud-cover metadata is not a point-level cloud assessment.
5. No SCL mask, spectral index, multi-date summary, or land-cover interpretation was produced by this run.
6. The five-point multispectral technical pilot remains separate and has not yet been executed.
7. The blind review remains blind: this audit deliberately reports no sample-specific interpretation.

## Next implementation sequence

1. Improve asset-access classification and candidate fallback so credential-gated items do not obscure usable public candidates.
2. Implement native-resolution multispectral window reads for the first five CSV rows, keeping 10 m and 20 m measurements distinct.
3. Apply SCL screening on its native 20 m grid; document any alignment needed for other grids rather than implying extra detail.
4. Calculate indices only from compatible, valid inputs and preserve per-band provenance.
5. Produce per-date point/neighbourhood summaries and only then evaluate whether temporal coverage is adequate.
6. Expand beyond five points only after the technical pilot passes its quality gates.

## Reproducibility

The source artifact was generated by the repository workflow above and retained as a GitHub Actions artifact for 14 days. The CSV audit counted rows by `status`, grouped by `sample_id`, and inspected failure notes. No imagery or derived raster was committed to Git.

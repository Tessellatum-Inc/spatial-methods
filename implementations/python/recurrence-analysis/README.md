# Recurrence analysis

NumPy implementation of fixed-threshold recurrence plots and standard recurrence-quantification measures (RR, DET, L, Lmax, DIV, ENTR, LAM, TT, Vmax) and a Rosenstein largest-Lyapunov-exponent estimator, with delay embedding, Chebyshev/Euclidean distance and a Theiler exclusion window. This is descriptive time-series analysis, not a causal test.

# Knox test for space-time interaction

The Knox test evaluates whether event pairs close in space are also close in
time more often than expected under a null model. For event i and j, define
spatial and temporal proximity indicators

    S_ij = I(distance(x_i,x_j) <= d)
    T_ij = I(abs(t_i-t_j) <= tau).

The observed statistic is

    K = sum_(i<j) S_ij T_ij.

A Monte Carlo reference distribution is generated by permuting event times
over fixed locations. The plus-one upper-tail p-value is

    p = (1 + count(K_b >= K_observed)) / (B + 1).

See [the Python implementation](../../implementations/python/knox-test/README.md).
The permutation test relies on exchangeability under the null. Temporal
trends, seasonality, observation-window effects and varying sampling
intensity can invalidate naive permutations. This O(N²) implementation is
not a space-time K function or scan statistic.

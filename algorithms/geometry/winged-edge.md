# Winged-edge data structure\n\nA winged-edge mesh stores, per undirected edge, its two endpoints, the predecessor and successor edge on each incident face, and the left/right incident faces. The implementation builds this static representation from consistently oriented polygon faces and rejects non-manifold edge incidence and inconsistent winding. It does not implement topology editing or geometric repair.\n\nSee [implementation](../../implementations/python/winged-edge/README.md).

# Quad-edge data structure\n\nThe implementation supplies the Guibas–Stolfi four-dart representation and core topological operators: make-edge, splice, connect and delete-edge, with primal/dual navigation identities. It is a topology substrate, not a complete Delaunay triangulator; geometric predicates, point location and embedding validation remain outside scope.\n\nSee [implementation](../../implementations/python/quad-edge/README.md).

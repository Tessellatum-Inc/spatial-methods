# Compendium provenance and authorship

**Record date:** 18 November 2026

## Project-owner statement

The project owner has confirmed that the *Spatial Analysis Algorithms: Complete Compendium* is their own project and compilation. The owner describes the underlying idea and direction as theirs, with the work developed collaboratively using AI assistants (including ChatGPT and Claude).

This statement records the owner's account of authorship and project provenance. It is not a legal opinion or a determination of copyright status in every component.

## What this establishes for the repository

- The compendium is a project-originated working compilation, not an unidentified third-party submission.
- The owner has authorised the project to continue using the compilation as the working source inventory for research, implementation planning and internal traceability.
- The page transcription preserves the supplied material and its provenance; it does not independently validate the technical claims or bibliographic details.
- AI assistance should be acknowledged where relevant, but it does not replace human review of methods, equations, references, code or claims.

## What it does not establish

A compilation can contain material with different origins and rights. The owner's authorship of the compilation does not by itself establish redistribution rights over third-party passages, tables, figures, datasets, software documentation, code samples or other incorporated assets.

For public release:

1. Keep original project explanations and diagrams distinguishable from quoted or adapted source material.
2. Cite primary sources for factual and technical claims.
3. Use short quotations only where justified; otherwise write original explanations and link to the source.
4. Keep third-party figures and datasets under their own applicable licences and attribution requirements.
5. Remove, replace or link to any incorporated material whose reuse basis is unclear.
6. Do not apply a blanket project licence to third-party material.

## Release treatment

The compendium can remain the project's research and traceability backbone. Public-facing lessons, implementations and notebooks should be original project deliverables with source citations and clearly stated implementation scope. The repository-wide code and documentation licence decisions remain separate and have not been made by this provenance record.

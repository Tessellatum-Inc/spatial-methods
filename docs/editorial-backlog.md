# Editorial Backlog

A working queue for deciding what Spatial Methods should investigate, produce, improve or publish. The backlog is deliberately question-led: it tracks useful work, not a rigid curriculum or a list of audience personas.

## Working rules

1. Capture promising questions and opportunities without committing to produce them.
2. Search existing explorations and resources before creating something new.
3. Prefer a useful, bounded investigation over an oversized topic treatment.
4. Separate discovery, research, practical verification, editorial review and publication.
5. Keep the queue small enough to act on. Re-score it when evidence or capacity changes.
6. Do not schedule publication dates until the work is sufficiently complete.
7. Every published item should have a canonical home, owner, status and review trigger.

## Status definitions

| Status | Meaning |
|---|---|
| Inbox | Captured, not yet assessed |
| Triage | Scope, value and duplication being assessed |
| Ready | Clear question, feasible next action and sufficient source access |
| In progress | Actively being researched or produced |
| Review | Evidence, technical claims, licences and editorial quality being checked |
| Ready to publish | Approved and packaged; awaiting release |
| Published | Live with canonical links |
| Monitoring | Worth tracking, but no immediate production |
| Deferred | Valid idea, currently lower priority |
| Closed | Duplicate, out of scope, infeasible or no longer useful |

## Prioritisation

Score each dimension from 1 (low) to 5 (high).

| Dimension | Question |
|---|---|
| User value | Does this help someone understand, investigate, practise, teach, build or apply something? |
| Strategic fit | Does it strengthen Spatial Methods' spatial and computational knowledge base? |
| Evidence opportunity | Can we access credible sources, data or a testable method? |
| Reuse and connection | Can the work connect or improve multiple existing resources? |
| Feasibility | Can we make a meaningful, bounded contribution with available capacity? |

**Priority score:** total out of 25. Use judgement, not score worship. A high score does not override safety, licensing, accuracy or feasibility concerns.

Suggested interpretation:
- **21–25:** strong candidate for the next production slot.
- **16–20:** develop scope or queue behind current work.
- **11–15:** monitor, narrow or combine with another item.
- **5–10:** defer or close unless new evidence changes its value.

## Capacity and work-in-progress

- Keep no more than **two substantial investigations** in active production at once.
- Small dispatches, corrections and maintenance may proceed alongside them when capacity allows.
- Do not start a new flagship exploration while an existing one is awaiting essential verification.
- Revisit the queue at each editorial planning session; avoid a large speculative publishing calendar.

## Definition of done

An item is complete when:
- its question and scope are clear;
- the evidence and source provenance are recorded;
- relevant technical claims have been checked;
- limitations and licensing are addressed;
- the output is linked to related work;
- the canonical artefact is published or the reason for closure is recorded;
- a review trigger is defined where the subject can change.
